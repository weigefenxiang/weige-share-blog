# 标准溶液计算审核 · Web 版

[StandardSolutionReviewSystem](https://github.com/weigefenxiang/StandardSolutionReviewSystem)(PyQt6 桌面版)的纯静态网页移植版。

一款用于实验室标准溶液标定、计算与审核的工具:支持温度校正、滴定管校正、单人四平行、双人八平行及相对极差自动计算(依据 GB/T 601)。

**纯 HTML + CSS + 原生 JavaScript,零依赖、零构建、无外链** —— 下载即用,上传到任意静态服务器即可部署。

## 功能特点

- ✅ 温度校正计算(内置 GB/T 601 体积补正值表,5~36℃ × 8 类溶液)
- ✅ 滴定管校正值修正(校正值 2 自动补充)
- ✅ 标液浓度自动计算(5 位有效数字)
- ✅ 单人四平行 / 双人八平行 / 相对极差 / 标液报出浓度
- ✅ 相对极差超限自动红色预警(四平行 ≤0.15%,八平行 ≤0.18%)
- ✅ 选择标液种类自动带出基准物质与摩尔质量;氯化锌专用公式(量取体积 × EDTA 浓度)
- ✅ Enter 一键计算 · 响应式布局,手机可用
- ✅ 界面缩放按钮(− / 100% / ＋):整页长宽等比放大缩小,比例自动记忆

## 支持的标准溶液

盐酸、氢氧化钠、硫酸、高锰酸钾、硝酸银、硫代硫酸钠、EDTA、氯化锌、氢氧化钾-乙醇、碳酸钠、水或水溶液(自定义摩尔质量)

## 使用方式

### 本地直接用

双击 `index.html`(或 `打开网页.bat`)即可,无需任何环境。

### 部署到 VPS(nginx 示例)

把整个目录上传到服务器,例如 `/var/www/ssrs`:

```nginx
server {
    listen 80;
    server_name your.domain.com;
    root /var/www/ssrs;
    index index.html;
}
```

### GitHub Pages

仓库 Settings → Pages → Deploy from a branch → 选择 `main` / root,保存即可。

## 本地测试(一键运行)

双击 `一键测试.bat`(或直接打开 `test/test.html`),浏览器内即时运行全部测试并显示报告:

- **校正表数据检查**:温度范围、列结构完整性与关键值抽查(表数据与测试向量均由 `tools/gen_vectors.py` 统一生成,与桌面版 `dbUtil.py` 数据同源)
- **舍入与格式化单元测试**:银行家舍入(ROUND_HALF_EVEN,含二进制精确平局如 36.5625→36.562)、有效数字、`Decimal prec=10` 均值修约语义
- **13 组同源算法向量比对**:由 Python 参考脚本(与桌面版 `Flu_Main.py` 同源算法)生成期望值,对网页版输出**逐位字符串比对**,覆盖全部校正列、氯化锌专用公式、表格上下边界温度、舍入平局与浓度跨数量级等边界
- **输入校验用例**:温度范围、非法数字、全角数字、无校正数据组合的错误提示

重新生成测试向量:`python tools/gen_vectors.py`(需 Python 3,仅开发时使用,部署无需)。

默认示例数据(NaOH 1 mol/L @23℃)的计算结果与桌面版 exe 截图逐位一致。

## 计算规则说明

| 项目 | 规则 |
|---|---|
| 温度校正值 | 表值 × 消耗体积 / 1000,保留 3 位小数(银行家舍入) |
| 滴定液实际体积 | 消耗体积 + 滴定管校正 + 温度校正 + 空白,5 位有效数字 |
| 标液浓度 | c = m×1000 / M / V;氯化锌:c = 量取体积 × c(EDTA) / V,5 位有效数字 |
| 平行均值 | 单人 4 次 / 双人 8 次平均,小数位与单次浓度一致(银行家舍入) |
| 报出浓度 | 八平行均值少保留一位小数 |
| 相对极差 | (最大 − 最小) / 均值,百分数保留 2 位小数 |

## 与桌面版的差异

1. **修正**:氢氧化钾-乙醇(0.1 mol/L)使用其专用温度校正列(桌面版因浓度值比较错误,该列永远不会命中而误用水的校正列)。
2. **改进**:校正表无数据的组合(如碳酸钠 31~36℃、氢氧化钾-乙醇 5~9℃、高锰酸钾 1 mol/L 等)给出明确的错误提示。
3. **新增**:相对极差超限时红色高亮并弹出警告。
4. **改进**:平行浓度均值为 0 时给出明确错误(桌面版此处为除零异常,弹出含糊的数据库错误)。
5. 温度输入允许首尾空格(桌面版会拒绝 `" 23 "`);全角数字自动归一化为半角(桌面版 `float()` 本就接受全角数字,两版行为一致)。
6. 未包含桌面版占位的"查询/保存"按钮;下拉框中的"配置人"名单未保留(公开部署避免暴露人名)。

除上述条目外,计算输出与桌面版**逐位一致**(包括银行家舍入的二进制精确平局、`Decimal prec=10` 的中间舍入、相对极差对浓度字符串按字典序排序取极值等细节行为)。

## 项目结构

```
├── index.html        # 单页应用
├── css/style.css     # 深色 Fluent 风格样式
├── js/data.js        # 温度体积校正表 + 溶液配置(替代 SQLite)
├── js/calc.js        # 计算引擎(十进制精确运算 + 银行家舍入)
├── js/app.js         # 界面交互
├── test/test.html    # 一键本地测试报告页
├── test/vectors.js   # Python 同源算法生成的测试向量
├── test/test.js      # 测试用例
├── tools/gen_vectors.py  # 与桌面版同源的参考实现(生成 data.js 与测试向量)
├── 一键测试.bat       # 双击运行全部测试
└── 打开网页.bat       # 双击打开应用
```
